Создание передвижения персонажа в 2D

В этом уроке мы напишем скрипт на языке C#, который позволит вашему игровому персонажу двигаться влево и вправо, а также прыгать с учетом законов физики движка Unity.

Шаг 1. Настройка компонентов

Убедитесь, что на вашем игровом объекте персонажа (Sprite) добавлены два обязательных компонента: Rigidbody2D (для физики) и BoxCollider2D (чтобы персонаж не проваливался сквозь землю).

⚠️ Важно: Ограничение вращения

В компоненте Rigidbody2D откройте вкладку Constraints и поставьте галочку напротив Freeze Rotation Z. Иначе ваш персонаж будет падать и крутиться как неваляшка при столкновениях.

Шаг 2. Пишем скрипт на C#

Создайте новый C# скрипт, назовите его PlayerMovement и откройте его. Замените код на следующий:

using UnityEngine;

public class PlayerMovement : MonoBehaviour
{
    public float speed = 5f;
    private Rigidbody2D rb;
    private float horizontalInput;

    void Start()
    {
        rb = GetComponent<Rigidbody2D>();
    }

    void Update()
    {
        // Считываем ввод стрелочек или клавиш A/D
        horizontalInput = Input.GetAxis("Horizontal");
    }

    void FixedUpdate()
    {
        // Применяем скорость к физическому телу
        rb.linearVelocity = new Vector2(horizontalInput * speed, rb.linearVelocity.y);
    }
}
