Установка игрового движка Unity

В этом уроке мы разберем, как правильно установить Unity и сопутствующие программы для комфортного программирования на C#.

Шаг 1. Скачивание Unity Hub

Unity Hub — это официальный менеджер, который позволяет управлять вашими проектами и загружать разные версии самого движка. Перейдите на официальный сайт Unity и скачайте версию для вашей операционной системы (Windows / macOS).

⚠️ Совет по лицензии

При первом входе в Unity Hub создайте аккаунт и активируйте бесплатную лицензию Personal. Она дает 100% функций движка и идеально подходит для студентов и инди-разработчиков.

Шаг 2. Выбор версии движка

Внутри Unity Hub перейдите в раздел Installs и нажмите Install Editor. Рекомендуется выбирать версию с пометкой LTS (Long Term Support) — это самые стабильные сборки, в которых нет багов и которые поддерживаются разработчиками несколько лет.

Шаг 3. Подключение сред разработки (IDE)

В процессе установки движка Hub предложит вам выбрать модули. Обязательно отметьте галочкой Microsoft Visual Studio Community — это свяжет ваш Unity с редактором кода, и вы получите автозаполнение геймдев-команд C# прямо при написании скриптов.
