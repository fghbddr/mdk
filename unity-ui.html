Создание игрового интерфейса (UI)

Игровой интерфейс (User Interface) отображает для игрока важную информацию: текущее количество здоровья, очки, собранные монеты или патроны. В Unity для этого используется система UI Toolkit или классический Canvas.

Шаг 1. Создание элементов интерфейса

Нажмите правой кнопкой мыши в панели Hierarchy и выберите UI -> Canvas. Холст (Canvas) — это невидимая плоскость, на которой будут размещаться все плоские элементы интерфейса поверх вашей игры. Внутри Canvas создайте элемент Text - TextMeshPro для отображения счета.

⚠️ Внимание: Тексты на русском языке

Стандартные шрифты Unity не поддерживают кириллицу. Чтобы текст на русском языке не отображался квадратиками, используйте инструмент TextMeshPro -> Font Asset Creator для импорта любого привычного шрифта (например, Arial или Roboto).

Шаг 2. Написание UI-менеджера на C#

Чтобы изменять текст счета из кода при подборе монеты, напишем простой скрипт-менеджер. Создайте C# скрипт UIManager и прикрепите его к Canvas:

using UnityEngine;
using TMPro; // Обязательное пространство имен для работы с текстом

public class UIManager : MonoBehaviour
{
    public TextMeshProUGUI scoreText;
    private int score = 0;

    public void AddScore(int points)
    {
        score += points;
        scoreText.text = "Монеты: " + score;
    }
}
