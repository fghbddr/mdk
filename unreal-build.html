Финальная сборка и упаковка проекта (Packaging)

Экспорт проекта в Unreal Engine 5 называется упаковкой (Packaging). Этот процесс превращает ваши тяжелые шейдеры, 3D-модели и Blueprint-логику в оптимизированную скомпилированную игру.

Шаг 1. Выбор главной сцены

Перед тем как начать сборку, движку нужно жестко указать, какая карта должна загружаться при старте приложения. Перейдите в верхнее меню Edit -> Project Settings, откройте вкладку Maps & Modes и в поле Game Default Map выберите карту вашего главного меню или первого уровня.

⚠️ Важно: Установка SDK для C++

Если в вашем проекте есть хотя бы один файл кода на C++, перед первой упаковкой Unreal Engine потребует обязательной установки компилятора Windows SDK через установщик Visual Studio, иначе сборка упадет с ошибкой AutomationTool.

Шаг 2. Настройка конфигурации (Build Configuration)

В верхней панели редактора нажмите на кнопку Platforms, выберите вашу целевую платформу (например, Windows). Перейдите в настройки конфигурации сборки. По умолчанию там стоит Development (версия для разработчиков с консолью отладки). Смените её на Shipping — это финальная чистая версия игры без лишнего веса и логов, готовая к публикации.

Шаг 3. Запуск упаковки проекта

В том же меню Platforms -> Windows нажмите на кнопку Package Project. Движок попросит вас указать пустую папку на диске для сохранения файлов. Выберите её, и начнется процесс компиляции шейдеров.
