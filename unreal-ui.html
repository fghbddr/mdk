Создание игрового интерфейса с помощью UMG

Система Unreal Motion Graphics (UMG) позволяет собирать интерфейсы любого уровня сложности с помощью визуального конструктора элементов (кнопок, текста, слайдеров шкалы здоровья).

Шаг 1. Создание Widget Blueprint

В панели Content Browser нажмите правой кнопкой мыши и перейдите в раздел User Interface -> Widget Blueprint. Выберите базовый класс UserWidget и назовите ассет, например, WBP_HUD. Откройте его двойным кликом.

⚠️ Правило иерархии: Canvas Panel

Любой виджет в Unreal Engine должен начинаться с контейнера. Первым делом перетащите элемент Canvas Panel из панели Palette на рабочую область. Только внутри него вы сможете свободно распределять и выравнивать другие текстовые и графические блоки.

Шаг 2. Вывод виджета на игровой экран

Сам по себе созданный виджет не появится в игре автоматически. Его нужно вызвать через логику. Откройте Blueprint уровня (Level Blueprint) или вашего персонажа, и соберите цепочку из нод Create Widget (выбрав ваш класс WBP_HUD) и последующей обязательной ноды Add to Viewport.

Шаг 3. Управление интерфейсом на C++ (Альтернатива)

Для создания сложных оптимизированных интерфейсов вы можете объявить базовый класс виджета на C++, а его дизайн настраивать уже в редакторе:

// Объявление элементов виджета в заголовочном файле C++ (.h)
#pragma once
#include "CoreMinimal.h"
#include "Blueprint/UserWidget.h"
#include "Runtime/UMG/Public/Components/TextBlock.h"
#include "MyUserWidget.generated.h"

UCLASS()
class MYPROJECT_API UMyUserWidget : public UUserWidget
{
    GENERATED_BODY()
public:
    // Позволяет связать переменную кода с текстовым блоком из Blueprint
    UPROPERTY(meta = (BindWidget))
    UTextBlock* ScoreText;
};
