Выбери игровой движок

Unity

Инди 2D / 3D Мобильные Язык: C#

Самый популярный выбор для независимых разработчиков. Идеален для мобильных игр, пиксельных 2D-платформеров и стильных 3D-проектов. Огромное комьюнити.

Открыть гайды по Unity

Unreal Engine

AAA Класс Реалистичный 3D ПК / Консоли Blueprints / C++

Мощный движок для создания графики нового поколения и масштабных проектов. Используется крупными студиями, но имеет бесплатный доступ для новичков.

Открыть гайды по Unreal

Godot Engine

100% Бесплатно Легковесный Лучший в 2D Open Source

Полностью бесплатный движок с открытым исходным кодом. Очень быстро запускается и работает даже на слабых ПК. Идеален для быстрых инди-стартов.

Открыть гайды по Godot

Construct 3

Без кода (No-Code) Только 2D Браузерные / HTML5 Для новичков

Движок для тех, кто вообще не хочет писать код. Логика строится на визуальных событиях. Идеален для первых шагов, гиперказуальных и браузерных игр.

Открыть гайды по Construct

Ren'Py

Визуальные новеллы Аниме / Квесты Низкий порог Язык: Python

Специализированный движок для создания текстовых квестов и визуальных новелл (в стиле Бесконечного Лета). Очень простой скриптовый язык программирования.

Открыть гайды по Ren'Py

RPG Maker

JRPG / Пиксели Своя база данных Ретро-стиль JS плагины

Культовый инструмент для создания классических ролевых игр сверху вниз (как старые Final Fantasy). Имеет встроенный редактор карт, персонажей и диалогов.

Открыть гайды по RPG Maker
