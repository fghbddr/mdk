Настройка передвижения персонажа в 3D

В Unreal Engine логику движения персонажа принято настраивать через систему визуальных скриптов Blueprints с использованием новой подсистемы Enhanced Input System.

Шаг 1. Настройка InputAction и InputMappingContext

В панели контента создайте два ассета: Input Action (например, IA_Move для ходьбы и IA_Look для вращения камеры) и свяжите их внутри Input Mapping Context с клавишами WASD и движениями мыши.

📐 Специфика 3D: Векторы направления

В отличие от 2D, где движение шло только по оси X, в 3D нам нужно получать направление взгляда камеры (Control Rotation), убирать из него наклон по вертикали и брать чистые векторы Get Forward Vector (для ходьбы вперед/назад) и Get Right Vector (для стрейфа влево/вправо).

Шаг 2. Логика в Blueprint класса Character

Откройте Blueprint вашего персонажа. Вызовите событие Enhanced Action IA_Move. Из значения "Action Value" вытяните оси X и Y, после чего подключите их к ноде Add Movement Input, передавая туда высчитанные векторы направления.

Шаг 3. Исходный код C++ альтернативы

Если для защиты вам нужно показать преподавателю именно текстовый код на C++ вместо визуальных блоков, используйте стандартную привязку осей в методе создания персонажа:

// Пример C++ кода для настройки ввода в UE5
void AMyCharacter::Move(const FInputActionValue& Value)
{
    FVector2D MovementVector = Value.Get<FVector2D>();
    if (Controller != nullptr)
    {
        const FRotator Rotation = Controller->GetControlRotation();
        const FRotator YawRotation(0, Rotation.Yaw, 0);
        const FVector ForwardDirection = FRotationMatrix(YawRotation).GetUnitAxis(EAxis::X);
        AddMovementInput(ForwardDirection, MovementVector.Y);
    }
}
