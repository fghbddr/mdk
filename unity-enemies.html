Создание искусственного интеллекта врагов

Сделаем так, чтобы в нашей игре появились противники, которые умеют самостоятельно патрулировать платформу из стороны в сторону и разворачиваться на её краях.

Шаг 1. Подготовка противника

Создайте новый спрайт врага, добавьте компоненты Rigidbody2D (поставьте Freeze Rotation Z) и BoxCollider2D. Также создайте и прикрепите новый скрипт с именем EnemyPatrol.

Шаг 2. Пишем скрипт патрулирования

Этот скрипт использует пустые объекты-маркеры (Points), чтобы определять границы своей зоны патрулирования. Открой скрипт врага и напиши следующий C# код:

using UnityEngine;

public class EnemyPatrol : MonoBehaviour
{
    public Transform leftPoint;
    public Transform rightPoint;
    public float speed = 2f;
    private bool movingRight = true;

    void Update()
    {
        if (movingRight)
        {
            transform.Translate(Vector2.right * speed * Time.deltaTime);
            if (transform.position.x >= rightPoint.position.x) movingRight = false;
        }
        else
        {
            transform.Translate(Vector2.left * speed * Time.deltaTime);
            if (transform.position.x <= leftPoint.position.x) movingRight = true;
        }
    }
}

🤖 Идея для улучшения

Вы можете добавить компонент Raycast2D, чтобы враг мог не просто ходить по точкам, а «видеть» перед собой игрока с помощью невидимого физического луча и включать режим погони.
